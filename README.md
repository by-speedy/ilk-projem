
# İlk Web Projem

HTML, CSS ve Git kullanarak geliştirdiğim ilk web projem.

## Proje Hakkında

Bu proje, web geliştirmeyi ve Git/GitHub kullanımını öğrenmek amacıyla hazırlanmıştır.

## Kullanılan Teknolojiler

- HTML — Web sayfasının yapısı
- CSS — Sayfanın tasarımı
- JavaScript — Butona tıklanınca mesaj gösterme
- Git — Sürüm kontrolü
- GitHub — Kodları barındırma
- GitHub Pages — Web sitesini yayınlama

## Canlı Demo

[Web sitemi ziyaret et](https://by-speedy.github.io/ilk-projem/)

## Özellikler

- Başlık ve açıklama alanı
- Hakkımda bölümü
- Renkli tasarım
- Tıklanabilir buton

## Kurulum

1. Depoyu bilgisayarına indir veya klonla.
2. `index.html` dosyasını tarayıcıda aç.

## Öğrendiklerim

- HTML ile sayfa oluşturma
- CSS ile tasarım yapma
- Git ile commit oluşturma
- GitHub'a kod gönderme
- GitHub Pages ile site yayınlama
